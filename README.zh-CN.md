APath 是一款 Windows 平台的 2D 游戏可行走区域地图编辑器。你可以在网格上绘制可行走区域，
预览三角剖分导航网格，并设置起点和终点，查找绕过障碍物的平滑路径。
导航核心也可以用于其他 C99 项目。

- 以像素为单位设置地图尺寸，支持边缘处不完整的单元格。
- 支持矩形填充与清除、撤销与重做、缩放和滚动。
- 基于三角形的 A* 寻路，使用漏斗算法进行任意角度的路径平滑。
- 使用紧凑的 `.amd` 文件格式，可通过 Windows 文件关联双击打开地图。
- 采用原生 Win32 英文界面，无需第三方运行时软件包。

## 构建

需要 **CMake 3.10+**、**Make** 和 **MinGW-w64**（包含 GCC 和 windres）。
应用支持 **Windows 7 及更高版本**。

```sh
mkdir build
cd build
cmake .. && make
```

默认构建类型为 Release。在 Linux 上，CMake 会优先选择已安装的 64 位 MinGW 编译器，
找不到时再选择 32 位 MinGW 编译器。生成的可执行文件为 `build/apath.exe`。

在 Windows 上，可使用 MSYS/MinGW shell，或指定 MinGW Makefiles 生成器：

```sh
mkdir build
cd build
cmake .. -G "MinGW Makefiles"
mingw32-make
```

如需明确指定生成 32 位程序：

```sh
mkdir build32
cd build32
cmake .. -DCMAKE_TOOLCHAIN_FILE=mingw32.cmake
make
```

生成 64 位程序时，使用 `mingw64.cmake`。

## 使用

运行 `apath.exe`，或通过命令行打开地图：

```text
apath.exe "path to map.amd"
```

### 创建和编辑地图

选择 File / New（文件 / 新建），输入单元格大小（Cell size）、X 方向长度（X length）和
Y 方向高度（Y height）。三项均以**像素**为单位，取值范围为 1 至 65535。
地图尺寸不必是单元格大小的整数倍：最右侧一列和最顶部一行会按指定尺寸裁切。
例如，一张 805 × 603 像素、单元格大小为 20 像素的地图，共有 41 列、31 行。

地图最多可包含 16,777,216 个单元格。用于记录可行走状态的位图最多占用 2 MiB，
三角剖分和撤销历史还需要额外内存。

坐标原点位于左下角，+X 向右，+Y 向上。绿色单元格表示可行走区域，白色单元格表示障碍区域。

| 操作 | 控制方式 |
| --- | --- |
| 新建 / 打开 / 保存 / 另存为 | Ctrl+N / Ctrl+O / Ctrl+S / Ctrl+Shift+S |
| 切换单个单元格的可行走状态 | 单击鼠标左键 |
| 清除单个单元格 | 单击鼠标右键 |
| 填充矩形区域 / 清除矩形区域 | 按住鼠标左键拖动 / 按住鼠标右键拖动 |
| 取消选择 | Escape |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Y |
| 以鼠标指针为中心缩放 | 鼠标滚轮 |
| 恢复适配窗口客户区的 1:1 视图 | Ctrl+H |
| 滚动 | 使用滚动条；拖动时靠近窗口边缘 |
| 切换编辑模式 / 三角剖分模式 | Ctrl+M |
| 在三角剖分模式中设置起点 / 终点 | 单击鼠标左键 / 单击鼠标右键 |
| 关于 | About 菜单 / F1 |

拖动时会预览矩形选区，松开对应的鼠标按键后，整个区域的修改会作为一次可撤销操作提交。
松开按键之前，可以缩小选区或反向拖动。按 Escape 或窗口失去鼠标捕获时，会取消本次选择。

### 视图与寻路

新建或打开地图时，窗口会根据地图的宽高比调整大小，并以 **1:1** 视图完整显示地图，
不显示滚动条。地图尺寸适合屏幕时，按存储的像素尺寸显示；较大的地图会等比例缩小到
显示器的工作区范围内，过小的地图则会放大到便于操作的窗口尺寸。
这个适配后的视图就是 1:1 缩放基准。完整单元格始终保持正方形，缩放时也不例外。

放大后会出现滚动条。滚轮缩放不能低于 1:1，按 Ctrl+H 可恢复完整地图视图。
手动调整窗口大小或最大化窗口时，地图仍保持原有比例，未使用的区域显示为白色。
对于非常狭长的地图，也可能保留白色边距，以便窗口正常操作。
缩放只影响显示，不会改变存储的地图尺寸或路径坐标。

按 Ctrl+M 可根据当前地图构建导航网格。网格线仍然可见，三角形边线以绿色显示。
网格较密时，会按固定间隔显示网格线，确保缩小视图后仍然清晰可读。

在三角剖分模式中，单击鼠标左键放置表示起点的**红色三角形**，单击鼠标右键放置表示终点的
**红色方块**。两个端点都必须位于可行走区域内。任一端点发生变化时，蓝色路径都会更新。
不连通的区域之间无法生成路径。切换模式会清除端点和路径。

路径由任意角度的直线段组成，适用于将移动对象视为点的场景。
路径可能接触障碍物边界，不会根据移动对象的半径预留通行间距。
三角形 A* 选定通道后，平滑过程会利用沿途完整的可行走矩形区域，
避免内部三角形边界造成多余的转折。结果是在该矩形通道内的最短路径，
但不保证在绕过障碍物的不同路线之间选出全局最短路径。

### 保存和打开地图

地图使用 `.amd` 扩展名，文件类型名称为 **apath map data**。
APath 启动时，若该扩展名尚未关联程序，会自动注册关联。
如果已经关联到当前可执行文件，则不会提示；如果已关联其他程序，则需要用户确认。
Windows 也可能要求在“默认应用”设置中选择 APath。

存在未保存的修改时，窗口标题会显示 `*`。新建、打开或关闭时，程序会在丢弃这些修改前提示。
保存时，只有新文件写入成功后才会替换目标文件。
